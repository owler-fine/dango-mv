# 投喂格式说明（放这里就行）

## 必需的两个文件

| 文件 | 放哪 | 格式 | 备注 |
|---|---|---|---|
| **歌** | `input/song.mp3`（或 .wav/.m4a/.flac） | 任意音频格式都行 | 最好是无损或 320k，别用微信压缩过的 |
| **歌词** | `input/lyrics.txt`（或 .lrc） | 见下方 | 纯文本就行 |

**文件夹位置**：`D:\deeepseek harness\_scratch\mv_project\input\`

---

## 歌词格式：三种任选

### 格式 A —— 最省事：纯文本，一行一句（推荐）

```
还没好好地感受
雪花绽放的气候
我们一起颤抖
会更明白什么是温柔
```

- 一行 = 一句 = 一个字幕
- 空行 = 段落分隔（前奏/主歌/副歌/间奏）
- 不需要写时间，**我用音频自动对齐**

### 格式 B —— 你已经有时轴：标准 LRC

```
[00:12.50]还没好好地感受
[00:16.20]雪花绽放的气候
```

- 有 LRC 就最好，直接精确到 0.01 秒，不用猜
- 从 QQ音乐/网易云/酷狗 直接导出即可

### 格式 C —— 带段落标记（想控制画面分组时用）

```
# 前奏
（纯音乐，画面走唱片机）

# 主歌
还没好好地感受
雪花绽放的气候

# 副歌
有时候 有时候
我会相信一切有尽头
```

- `# 段落名` 用来告诉我哪段是主歌、哪段是副歌
- `（括号内容）` 是画面说明，不当歌词

---

## 可选：风格指令

如果你想指定画面风格，另存一个 `input/style.txt`：

```
风格：复刻《红豆》那条
主色：暖粉 + 青绿 + 红
角色：红豆 + 白团子（沿用现有）
特殊要求：副歌要每拍一刀快切
```

不写也行，默认就按《红豆》那套。

---

## 我能自动搞定的部分（不用你操心）

| 环节 | 怎么做 |
|---|---|
| **测速 / 找拍** | 频谱通量 + IOI 直方图，出 BPM 和拍点 |
| **歌词对时间轴** | 音频转文字（faster-whisper）+ 你给的文本做强制对齐 |
| **切分镜头** | 按句子 + 拍点自动分配镜头时长 |
| **识别段落** | 按 RMS 能量曲线自动切主歌/副歌/间奏 |
| **字幕分行** | 太长自动断句，中间留全角空格 |

---

## 如果你只有音频、连歌词都没有

那也行。我直接跑语音识别出歌词草稿，你再改错字。**但准确率不如你直接给文本**（尤其是有和声/混响的歌）。
